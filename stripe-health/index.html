What it checks

Can you get paid?

Charges, payouts, and anything Stripe is waiting for.

What drains your balance?

Negative balances and recurring fees you may have forgotten, such as a custom-domain subscription.

Why do payments fail?

Failed-payment rate and the payment methods your customers actually see.

Is your site told about sales?

Dead or missing webhooks, so orders and deliveries don't depend on luck.

Is the customer experience complete?

Customer portal, tax registration, and a redirect after purchase.

Your key never leaves your machine

You run the check yourself. It makes read-only requests to Stripe from your own computer, prints a report, and saves nothing. Never send anyone your secret key, including us. If you want us to run it for you, create a restricted read-only key, send it once, and delete it afterwards.

How to run it

  1. Create a restricted key. Stripe Dashboard → Developers → API keys → Create restricted key. Give it Read access only.
  2. Run the script. You need Python 3. In a terminal:STRIPE_KEY=rk_live_… python3 stripe_health_check.py
  3. Read your score. You get a score out of 100, a grade, and each issue in English and Arabic. Then delete the key.
