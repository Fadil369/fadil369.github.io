One platform, three products

BrainSAIT is a bilingual (EN/AR) healthcare AI platform for the Saudi market, built around NPHIES and FHIR R4. BPR establishes clinician identity; ClinicFlow runs the clinic encounter; BOS provides the shared back office.

Status: BPR is live on GitHub Pages with a HF dataset (3 configs, FHIR R4 bundles, deployable wizard). ClinicFlow is a single-page reception pilot. BOS scope is being defined.
Next: Polish BPR wizard & profiles → expand ClinicFlow → build BOS MVP → combined launch.
